# Art Widgets

Интерактивные механики для рассказа об истории искусства. Каждая механика — самостоятельный
Vue-компонент: получает данные через props, ничего не знает о странице и может жить где угодно.

## Структура

```
packages/
  core/        типы, i18n (ru/en), даты, общие composables (usePanZoom, useStepTimer)
  ui/          дизайн-токены (tokens.css), шрифты (fonts.css), иконки, Icon, IconButton, SegmentedProgress
  node-card/   карточка-нода: лицо, оборот, свёрнутый кружок
  story/       сторис-тур по картине с точками и зумом
  time-map/    карта с ползунком времени и периодами
apps/
  playground/  Nuxt-витрина, где механики собраны на одной странице
    app/       код витрины (Nuxt 4): app.vue, pages/, assets/, data/ — `~` указывает сюда
    public/    статика, в том числе слои карты (public/geo)
```

Нужен Node 24 (как и на Vercel, см. `engines` в `package.json`); витрина — на Nuxt 4.

## Команды

```bash
npm install         # один раз, в корне
npm run dev         # витрина на http://localhost:3000 (?lang=ru — русская версия, ?year=1453 — карта на этом годе)
npm run typecheck   # типы пакетов и витрины, включая JSON-данные
npm run build       # продакшн-сборка витрины (см. «Ограничения»)
```

На GitHub при каждом коммите и пул-реквесте те же проверки запускаются сами (`.github/workflows/checks.yml`):
типы и `npm run geo:check` — проверка данных карты.

## Контракт механики

- **Данные — только через props:** `data` и необязательный `locale`. Схема данных — TypeScript-тип
  в `types.ts` пакета; витрина проверяет JSON по этим типам.
- **Ничего глобального:** никаких слушателей на `window` и поиска по селекторам — только template refs
  и события на своём корне. На странице может быть несколько экземпляров.
- **Внешний вид — через токены:** цвета (чёрное и немного золота), шрифты, радиусы и длительности берутся из
  CSS-переменных `--aw-*` в `packages/ui/src/tokens.css`. Шрифты: Inter Tight — заголовки, Inter — текст,
  JetBrains Mono — подписи и даты, курсив Source Serif 4 — названия картин. Все с кириллицей, `fonts.css`
  подключает их локально.
- **Раскладка — по ширине виджета:** сторис и карта перестраиваются через container queries, то есть
  по собственной ширине, а не по ширине окна. Это важно для встраивания.
- **Тексты:** строки интерфейса — `t('key')` из `useI18n()`, контент — `l(value)`, где `value` —
  строка или `{ ru, en }`.
- **Даты — числа:** отрицательные — до н. э. Строки вида «c. 6500–3800 BCE» / «ок. 6500–3800 до н. э.»
  собираются при выводе (`year`, `yearRange`).

## Историческая карта: данные

Карта охватывает время от 10 000 года до н. э. до сегодняшнего дня. Ползунок нелинейный (`timeScale: "sqrt"`):
последним векам отдано больше места, чем глубокой древности. Линия ползунка разделена на эпохи (`eras`:
название и год начала, по традиционной периодизации), под ней подписана текущая; над ней тонкой нитью идут
«эпохи идей» (`ideas`: осевое время, Возрождение, Просвещение), подписана только та, в которой сейчас год.
Page Up и Page Down переходят к соседней эпохе.

Точки и государства открывают одну и ту же панель. Точка — цивилизация, её история рассказана периодами,
которые идут встык от основания. Период — это глава, и у главы на карте есть:

- `states` — свои государства (английские названия, как в слое государств): Мин для «Династии Мин»;
- `under` — чьей землёй она была, когда не своей: Римская империя для «Римского Египта»;
- `at` — где стоит точка в эту главу, обычно столица: Пекин для Мин, Никея в 1204–1261 годах.

Клик по точке или по любому государству цивилизации открывает её историю на главе текущего года. Над
главой видно, чем она была: «государство», «в составе: Аббасидский халифат» или «культура» (нет ни
`states`, ни `under`). Её государства подсвечены на карте. Ссылки на Википедию ведут к статье о
цивилизации и о государстве главы. Государство, которое ничьей главой не является, открывается само по
себе: годы, название, Википедия. Панель закрывается, когда то, что в ней, уходит с карты. Названия
государств на карте — кнопки: открываются кликом и с клавиатуры (Tab, Enter). Сдвинутое, чтобы не
налезать на соседей, название остаётся внутри своего государства, иначе оно не показывается. Годы и
статьи государств — `public/geo/polities/info.json`, грузятся при первом клике. На узком экране рамка
карты выше (4:3), а сама карта сохраняет пропорции и прокручивается вбок.
Карта принимает `year` (год при открытии) и сообщает о движении ползунка событием `update:year`; витрина
так связывает её с адресом страницы (`?year=`).

Физическая география собирается скриптом и лежит в `apps/playground/public/geo/`:

```bash
npm run geo:build
```

- **Береговые линии эпох.** Рельеф суши и дна NOAA ETOPO1 (шаг 1/6°) «заливается» от океана до уровня моря
  эпохи. Уровни моря взяты по Lambeck et al. 2014 и задаются в `tools/geo/config.mjs`. Впадины, не связанные
  с морем (Мёртвое море, Каттара), сушей и остаются. Мегачад строится так же, по отметке древних берегов.
- **Реки, озёра и нынешний берег** — Natural Earth.
- **Исходники** скачиваются при первом запуске во временную папку системы (`art-widgets-geo`), в проект не
  попадают. Все источники — общественное достояние.

**Государства** — из [Cliopatria](https://github.com/Seshat-Global-History-Databank/cliopatria) v0.2.2
(Seshat Global History Databank, CC BY 4.0): около 1600 государств с 3400 года до н. э. по 2024 год, границы
по 200+ региональным источникам с экспертной проверкой. Версия закреплена в `tools/geo/polities.mjs`
(`CLIOPATRIA_VERSION`): новая может переименовать или перерисовать государства, и правки ниже придётся
сверить заново — сборка предупреждает о правках, которые больше ни к чему не применились. Слой собирается
отдельно:

```bash
npm run geo:polities
```

- Записи типа RELATION (составные империи поверх своих частей) отброшены; «зонтики» с названием в скобках
  (королевство с вассалами, империя с колониями) рисуются пунктирным контуром без заливки.
- Контуры упрощены до 0,1°, координаты хранятся в сотых долях градуса, повторяющиеся кольца — один раз.
  Острова меньше 1000 км² упрощаются мягче, чтобы не исчезнуть; маленькие государства (Мальдивы, Багамы)
  сохраняют все свои острова. Слой разбит на ~50 файлов по времени (`public/geo/polities/`); карта грузит
  только нужный.
- Русские названия — по английской статье Википедии через Wikidata/Википедию. Собственные ссылки Cliopatria
  на Wikidata местами ошибочны, поэтому не используются.
- **Проверка дат:** годы каждой записи сверяются с годами основания и распада по Wikidata; расхождения больше
  25 лет попадают в `tools/geo/polity-check.md`. Подтверждённые ошибки (например, «Ngô Dynasty» на
  1056–1406 годы — на деле Дайвьет; Кабинда за Португалией после 1975-го) исправляются списком
  `CORRECTIONS` в `tools/geo/config.mjs`: переименование, удаление части земли или записи — только на
  свои годы, длинная запись разрезается. `split` выделяет из записи части в заданных рамках под своим
  именем (Нигерия внутри «Золотого Берега», доминионы внутри «Британской колониальной империи»),
  `control` превращает запись в землю под контролем соперника — штриховкой поверх государства (районы
  КПК внутри Китайской Республики до 1945-го). Русские названия, которые не дала Википедия (латиница,
  статья о событии вместо государства, режим вместо страны — «Франция», а не «Пятая республика»), — в
  `RUSSIAN_NAMES` там же.
- **Наложения:** если заморскую часть государства в те же годы целиком держит другое государство, а
  столицы (по Wikidata) в ней нет, она из записи убирается (Алжир у Франции после 1962-го, Оман у
  Великобритании). Государство, чью землю почти целиком держат двое и больше других, рисуется контуром
  поверх них (Киевская Русь над княжествами). Меньшие государства рисуются поверх больших. Спорные
  современные границы (`DISPUTED`) это правило не трогает — для них есть следующее.
- **Границы по международному праву** (`DE_JURE` там же). Cliopatria рисует, кто землю держал; карта —
  кому она принадлежит по резолюциям ООН и договорам. Аннексии, оккупации и самопровозглашённые
  государства, которые ООН признала недействительными или не признало ни одно государство — член ООН,
  не меняют принадлежности земли: она остаётся у законного государства, а тот, кто её держал, рисуется
  поверх **штриховкой** (в легенде — «Оккупация»; в панели государства — «Под оккупацией: …» или, для
  непризнанных властей, «Под контролем: …»). Сегодня это Крым и Донбасс (Украина), Приднестровье
  (Молдова), Абхазия и Южная Осетия (Грузия), Карабах до 2023-го (Азербайджан), Северный Кипр, Голаны,
  Палестинские территории, Западная Сахара; в прошлом — Синай, Намибия 1966–1989, Восточный Тимор,
  Кувейт 1990-го, Афганистан 1979–1982; оккупации Первой мировой (Бельгия, Сербия, Румыния) и Второй
  (Эфиопия, Австрия, Чехословакия, Албания, Польша, страны Балтии до 1991-го, Дания, Норвегия, Бенилюкс,
  Франция, Греция, Югославия, запад СССР, Китай, Юго-Восточная Азия, Иран, Ирак, Исландия), союзная
  оккупация Германии, Австрии и Японии. Без штриховки возвращена земля, которую Cliopatria по ошибке
  отдала союзнику: Польша, Чехословакия 1945–1952 (у Cliopatria — СССР), Южный Вьетнам 1967–1972 (у
  Cliopatria — США), Западный и Восточный Берлин. `held` ограничивает правило перечисленными держателями
  (партизаны Югославии — не оккупанты), `hatch: 'all'` штрихует всю спорную область, как бы её ни
  рисовала Cliopatria. Тонкие полоски на границах, где два источника расходятся, отбрасываются. У каждого
  правила записано основание. Контуры спорных земель — из Natural Earth (`ne_10m_admin_0_disputed_areas`,
  общественное достояние), вырезание — `polygon-clipping`. Как в Cliopatria оставлены места, где договор
  сам задаёт линию или статус не решён: Кашмир по линии контроля (Симлское соглашение 1972 года), Косово,
  Тайвань, южные Курилы; занятые в 2022 году части Запорожской и Херсонской областей Cliopatria
  оставляет Украине, а Natural Earth их не размечает.
- **Дыры** (`FILLS` там же): землю, которую Cliopatria не отдаёт никому, хотя всё вокруг занято (Чукотка
  за 180-м меридианом), получает тот, кто держит соседнюю точку.
- **Пропуски:** если Cliopatria на несколько лет (до 30) выпускает государство и его землю никто не держит
  (Мексика в 1913–1919 годах), берутся границы соседней по времени записи.
- **Подписи** стоят в глубине той части государства, где столица, иначе — самой большой части.
- Всё, что сборка поменяла автоматически, перечислено в `tools/geo/polity-check.md`.
- **Проверка после сборки** (`npm run geo:check`, запускается сама после `geo:polities`): слой покрывает
  все годы, у каждого названия есть русская форма и оно не статья о событии, подписи внутри своих
  государств, а контрольные места принадлежат нужному государству в нужный год (Москва в 2000-м — Россия
  с заливкой, Крым в 2024-м — Украина и т. д., список `PLACES` в `tools/geo/check.mjs`). Главы
  цивилизаций идут встык и называют существующие государства, одно государство — глава только одной
  цивилизации, а год за годом точка стоит в своём государстве главы, и под ней нет чужого государства, не
  указанного в `under`. Расхождение до 30 лет допускается: Cliopatria даёт границы с шагом в десятилетия.
  Два закрашенных государства не делят большую землю (кроме оговорённых в `NESTED`), и у двух государств
  на карте одновременно нет одного русского названия. При ошибке команда завершается с кодом 1 и списком.

Вручную в данных карты (`features` в `apps/playground/app/data/map-ancient.json`) остались только то, чего
нет в Cliopatria: археологические культуры до государств, ледники, бывшие берега, древние русла и названия
исчезнувших земель, а также земли коренных народов, где на карте нет государств, до прихода колониальных
границ (аборигены Австралии, инуиты, народы Великих равнин и Субарктики, Амазонии, мапуче и теуэльче,
туареги, койсанские народы, народы Сибири). Их даты сверены с Википедией (октябрь 2026). У каждой
области есть `from` и `to`;
координаты — `[долгота, широта]`. `asTimeMapData()` проверяет данные при загрузке.
Точки с историями видны от `founded` до `until` или до конца последнего периода.

Упрощения: уровень моря одинаков для всей планеты (без поднятия суши после ледников и роста дельт),
Каспий и Балтика — в нынешних уровнях, Чёрное море — на уровне океана. Культуры и ледники нарисованы
приблизительно. Границы Cliopatria — тоже реконструкция: у древних государств они часто неизменны веками
просто потому, что источников мало.

## Новая механика

1. Создать `packages/<имя>/src/index.ts` и `package.json` по образцу соседних пакетов.
2. Добавить алиас в `aliases.ts` (пути в `tsconfig.json` подхватятся сами).
3. Вызвать `provideI18n(() => props.locale)` в корневом компоненте.

## Почему алиасы, а не npm workspaces

Репозиторий лежит на диске exFAT, а exFAT не поддерживает симлинки, на которых держатся
workspaces (npm и pnpm). Поэтому пакеты связаны алиасами путей (`aliases.ts` + `paths` в
`tsconfig.json`), а зависимости ставятся один раз в корне. У каждого пакета всё равно есть свой
`package.json` — он понадобится, когда механики начнут собираться отдельно.

## Ограничения

- **`npm run build` падает на exFAT:** сборщик Nitro ожидает от `readlink` ошибку `EINVAL`, а на
  exFAT Node возвращает `EISDIR`. Dev-сервер работает. Сборка проходит, если проект лежит на NTFS.
- **Ссылки на источники** в `apps/playground/app/data/portraits.json` — заглушки `example.com`.
